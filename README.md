# E-commerce Fulfilment & Return Analysis

基于 128,975 条真实电商订单（2022 Q2，印度站），分析履约方式
（Amazon 代履约 vs 商家自发货）与订单结果的关系，并核查退货率指标的可用性。

## 业务问题

1. 两种履约方式的取消率、退货率是否存在差异？
2. 该差异在不同品类、地区、客单价区间是否稳定？
3. 退货率这个指标本身，是否支持跨履约方式比较？

## 数据

- 来源：Kaggle — E-Commerce Sales Dataset
- 规模：128,975 行 × 24 列
- 时间范围：2022-03-31 至 2022-06-29（约 3 个月）
- 关键字段：order_id、order_date、status、fulfilment、category、qty、amount、ship_state
- 数据质量：`amount` 缺失 7,795 条（其中 7,566 条为取消订单）；`courier_status` 缺失 6,872 条

## 方法

1. **建库与导入**：MySQL 8.0 建表，日期用 `STR_TO_DATE` 转换，空值用 `NULLIF` 保留为 NULL
2. **SQL 分析**：周度趋势、品类退货率、履约方式对比、客单价分层、州级品类排名（窗口函数）
3. **口径核查**：拆分退货状态明细，验证指标是否可比

## 主要结果

| 指标 | Merchant 自发货 | Amazon 代履约 |
|---|---|---|
| 订单数 | 39,277 | 89,698 |
| 取消单数 | 6,861 | 11,471 |
| 取消率 | 17.47% | 12.79% |
| 已发货退货率 | 6.51% | 0.00% |

## 主要发现

1. **Amazon 退货率 0.00% 是口径问题，不代表履约质量。**
   全部 2,115 条退货类记录均归属 Merchant。`Shipped - Returned to Seller` 仅统计
   “退回卖家”的退货，Amazon 渠道的退货回流至平台仓库，不进入该字段。因此退货率
   无法跨履约方式比较。

2. **取消率差异稳定存在，但只能表述为相关。**
   Merchant 取消率高出约 4.7 个百分点。两种履约方式所覆盖的商品结构与地区分布不同，
   现有数据无法排除选择偏差，不能推断因果。

3. **客单价与退货率无显著关系。**
   四个客单价区间的退货率分别为 1.62% / 1.82% / 1.75% / 1.85%，差异在噪声范围内。
   （2,000 以上区间仅 54 单，样本过小，不作单独结论。）

4. **周度 GMV 在 2022-W14 达到峰值后缓慢下行。**
   W13 与 W26 为不完整周（分别只有 2 天、3 天），已在趋势分析中排除。

## 结论与建议

- 履约方式与取消率存在相关关系，建议对 Merchant 渠道商品补充库存与发货时效校验
- 退货率需补充 Amazon 渠道数据后才具备可比性
- 本次分析仅覆盖 2022 Q2，未排除季节性因素

## 局限

- 数据为卖家视角报表，Amazon 渠道的退货与售后数据缺失
- 时间跨度仅 3 个月，无法识别年度趋势
- 未包含促销标记的有效数据，大促影响未剥离
